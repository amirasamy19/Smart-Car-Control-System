# Smart Car Control System

ESP32-based smart car control system with Node-RED dashboard and real-time robot control.

---

## Project Overview

This project is a smart robotic car controlled through a Node-RED dashboard using ESP32 and serial communication.

The system includes:
- Login authentication
- Robot movement control
- Auto mode
- Real-time distance monitoring
- Dashboard interface

---

## Technologies Used

- ESP32
- Node-RED
- JSON
- Serial Communication
- Ultrasonic Sensor
- L298N Motor Driver

---

## Features

- Forward / Back / Left / Right movement
- Auto driving mode
- Login authentication system
- Real-time distance monitoring
- Dashboard control interface
- CSV data logging

## Dashboard Functions

The Node-RED dashboard allows users to:
- Control robot movement
- Monitor distance values
